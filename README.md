# 局域网唤醒（Wake-on-LAN）

用手机一键唤醒家里的电脑。为 **红米 / Redmi（HyperOS、MIUI）** 适配，安装包约 114 KB，无需登录、无需服务器。

- **本地唤醒**：手机连着家里 Wi-Fi 时，点一下设备卡片即可发出唤醒包。
- **飞书远程唤醒**（可选）：人在外面时，用飞书给机器人发一句 `/wake 书房台式机`，家里常驻的手机收到后发出唤醒包，并把结果回复到飞书。

> 本应用**不做在线检测**：不 ping、不扫描网段、不上报任何数据。MAC / IP / 端口由你自己核对，
> 程序只负责把格式正确的魔术包发出去 —— 这也是它能稳定唤醒的原因。

---

## 功能

| 功能 | 说明 |
| --- | --- |
| 设备列表 | 保存多台电脑的名称、MAC、IP、端口与备注，可编辑 / 删除 / 复制 MAC |
| 一键唤醒 | 点击设备卡片立即发出一个标准魔术包（102 字节），没有任何前置检测 |
| 自动兜底 | 填了 IP 就先单播；关机时电脑不回 ARP、单播包发不出去，会自动改用广播重发（广播不依赖 ARP，最可靠） |
| 只走 Wi-Fi | 即使手机同时开着移动数据，唤醒包也只从 Wi-Fi 发出 |
| 状态面板 | 顶部显示当前 Wi-Fi、本机 IP / 掩码与广播地址，用来确认手机是否与电脑在同一网段 |
| 设置 | 默认唤醒端口、每个目标发送次数、是否同时向端口 7 发送 |
| 飞书远程唤醒 | 可选功能，见下方专节 |

基础唤醒只用 3 个安装期权限（都与网络有关），**装好即用、不弹授权框**；只有启用飞书功能时才会申请
「通知」权限（前台服务常驻需要）。

## 安装

1. **取得安装包**：仓库不存放 APK —— 可按 [BUILD.md](BUILD.md) 自行构建（Windows 上一条命令），或使用他人分享给你的 APK。
2. **传到手机**：微信文件传输 / 数据线 / 局域网均可。
3. **点击安装**：用「文件管理」打开 APK 安装。
4. **如果被系统拦截**：
   - 关闭「纯净模式」：设置 → 应用设置 → 应用管理 → 右上角设置图标 → 纯净模式 → 关闭；
   - 允许安装未知应用：设置 → 应用设置 → 权限管理 → 安装未知应用 → 允许「文件管理」；
   - 弹出「安全检测 / 应用宝扫描」时选「继续安装」。
5. **确认联网权限**：设置 → 应用设置 → 应用管理 → 局域网唤醒 → 权限 → 若有「联网 / 网络访问」项需允许。

> 覆盖升级失败时：说明两次构建用的签名证书不同（证书不入库），先卸载旧版再安装即可。

## 使用

### 添加设备

右上角 `+`，填**名称**和 **MAC**（必填），IPv4 与备注可选。

- **查 MAC**：Windows 上 `cmd` 执行 `ipconfig /all`，看对应网卡的「物理地址」；
- **IPv4 建议留空**：留空就直接走广播，电脑关机也能收到，且不依赖 ARP；
- 想固定 IP 的话，建议在路由器上做 DHCP 静态绑定（MAC ↔ IP）。

### 唤醒

点击设备卡片 → 立即发出 1 个魔术包，并提示结果：

```
已发送 1 个魔术包 → 192.168.0.3 :9
```

若提示「已自动改用广播」，说明单播发不出去、程序已自动兜底重发，属正常现象
（想不再出现这条提示，把该设备的 IPv4 留空即可）。

**长按卡片**：编辑 / 复制 MAC / 删除。

### 设置

右上角「设置」：

- **默认唤醒端口**：默认 9，老网卡可能用 7；
- **每个目标发送次数**：默认 1；偶尔唤不醒可调到 3~5；
- **同时向端口 7 发送**：勾选后每个目标会向 9 和 7 各发一次。

## 目标电脑需要满足的条件（关键）

Wake-on-LAN 必须**先在电脑端配好**，否则手机发再多包也叫不醒：

1. **用有线网卡**：绝大多数无线网卡不支持 WOL；关机后网口指示灯应仍然亮着。
2. **BIOS/UEFI**：开启 `Wake on LAN` / `Power On By PCI-E` / `Resume By LAN`（不同主板叫法不同）。
3. **Windows 网卡属性**（设备管理器 → 网络适配器 → 属性）：
   - 「电源管理」页：勾选「允许此设备唤醒计算机」与「只允许幻数据包唤醒计算机」；
   - 「高级」页：`Wake on Magic Packet` 设为 Enabled；`节能以太网 / 绿色以太网` 建议关闭；
     `关机网络唤醒（Shutdown Wake-On-Lan）` 设为 Enabled。
4. **关闭 Windows 快速启动**：控制面板 → 电源选项 → 选择电源按钮的功能 → 更改当前不可用的设置 →
   取消勾选「启用快速启动」。**这是关机（S5）唤醒失败最常见的原因。**
5. **与手机在同一网段**：本应用基于二层单播 / 广播，跨网段需要路由器额外配置。

## 飞书远程唤醒（可选）

**一句话**：家里常驻一台插电、常连家里 Wi-Fi 的手机跑这个 App；你在任何地方用飞书发指令，
它负责发出唤醒包并把结果回复给你。

> 为什么需要一台常驻设备：WOL 是二层广播，必须由**身处内网**的设备发出，公网服务器代替不了它。
> 可以是旧手机、平板，与目标电脑同一个网段即可。

### 第一步：飞书侧配置（约 5 分钟，需管理员）

1. 打开 https://open.feishu.cn/app → **创建企业自建应用** → 记下 **App ID** 与 **App Secret**。
2. **应用能力 → 添加应用能力 → 机器人**。
3. **权限管理** 开通三项：`im:message:readonly`、`im:message:send_as_bot`、`contact:user.id:readonly`。
   （不需要群聊权限，也**不需要建群或加好友** —— 只用单聊。）
4. **版本管理与发布 → 创建版本** → 可用范围**只勾你自己** → 申请发布。
   ⚠️ 权限与机器人能力**必须发布之后才生效**，以后每改一次权限都要重新发一版。
5. 在飞书 **工作台** 里打开该应用一次。

### 第二步：在 App 里绑定

右上角「设置」→「飞书远程唤醒…」：

1. 填 **App ID**、**App Secret**、**我的手机号**；
2. 点 **「连接并获取会话」** —— App 会自动取凭证、用手机号换 `open_id`，并让机器人给你发一条
   「🔗 飞书远程唤醒已连接」，会话 ID 自动保存；
3. 飞书里收到那条消息即表示绑定完成，**以后直接在它与机器人的单聊里发指令**；
4. 「发送测试消息」可随时验证链路是否通畅。

### 指令

| 指令 | 说明 |
| --- | --- |
| `/wake 书房台式机` | 发唤醒包并回复结果（也支持 `/唤醒`，或用序号 `/wake 1`） |
| `/list` 或 `/设备` | 列出设备与序号 |
| `/help` | 指令帮助 |
| 其它文本 | 静默忽略（不回复） |

### 让它常驻后台（HyperOS 必做）

息屏后服务可能被系统清理，必须放行：

1. 设置 → 应用设置 → 应用管理 → **局域网唤醒** → 省电策略 → **无限制**；
2. 允许**自启动**；
3. 最近任务里**下拉锁定**本应用；
4. 通知栏会常驻一条「飞书远程唤醒」通知（文案 `待命中 · 每 N 秒检查一次指令`），
   **它就是判断服务是否活着的依据**，请不要关掉它。

验证方法：锁屏 30 分钟后从飞书发一条指令，应在 10~60 秒内收到回复。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示「未连接 Wi-Fi」 | 手机没连 Wi-Fi 或处于飞行模式；唤醒包必须从内网发出 |
| 提示「已自动改用广播」 | 正常兜底（填的 IP 解析不到 ARP）；把 IPv4 留空即可不再出现 |
| 提示已发送，但电脑没醒 | 电脑端没配好，见「目标电脑需要满足的条件」，尤其**快速启动**与 BIOS |
| 手机与电脑不在同一网段 | 看顶部状态面板的广播地址是否与电脑 IP 同网段；很多路由器把 2.4G/5G 或访客网络分到了不同网段 |
| 点了完全没反应 | 手机不在内网 Wi-Fi；若用飞书功能，检查服务是否被系统清理（见「让它常驻后台」） |
| 飞书发指令没回复 | 先看通知栏那条常驻通知是否还在，再看 App 设置页里的「最近错误」 |
| 提示 `code=99991672` / `code=230027` | 飞书权限没开通，或开通后没有重新发布版本 |
| 提示 `code=99991664` | App Secret 被重置了：复制当前 Secret 填回 App 保存 |
| 提示 `code=232034` | 应用没在飞书工作台里启用过 |
| 覆盖安装失败 | 两次构建的签名证书不同（证书不入库），先卸载旧版再装 |

> 网络超时、飞书服务端偶发错误（如 `code=2200`）属于**临时故障，程序只会自己重试，不会打扰你**；
> 只有需要你动手处理的错误（权限、凭证、应用未启用）才会发消息提醒。

## 隐私

- 只与飞书官方域名 `open.feishu.cn` 通信，不向其它服务器发送任何数据；
- 没有统计、没有上报、没有在线检测；
- `App Secret` 仅以明文保存在手机本机（应用私有目录）；建议飞书侧只申请上述三项最小权限、
  可用范围只勾自己，不再使用时在飞书后台重置 Secret。
